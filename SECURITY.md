# Security policy

Security fixes target the latest source and release; older versions have no separate maintenance commitment.

Report suspected vulnerabilities privately to the repository maintainer. Use GitHub private vulnerability reporting if enabled; otherwise arrange a private channel with the maintainer before sharing sensitive details. Include the affected version, reproduction steps, and impact, with credentials and private recordings removed.

The editor processes local media with bundled native video tools. Dependency origins and checksums are recorded in `Development/scripts/dependencies.json`; keep the complete portable bundle and its license notices together.
