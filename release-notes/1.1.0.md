# Simple Video Editor 1.1.0

Unreleased Rust candidate. Keep the PR open for user testing; no tag or release has been published.

- Replaces the C#/WPF application with a portable Rust editor requiring no .NET runtime.
- Preserves linked audio/video edits, cuts, gaps, legacy projects, undo/redo, recovery and missing-file relinking.
- Imports PQ/HLG and mixes SDR/HDR sources using explicit output profiles and saved source interpretation overrides.
- Adds 10-bit HDR10 AV1/HEVC exports, SDR tone mapping, native display-aware preview and software SDR fallback.
- Adds per-section audio stream, gain, mute and fades, plus non-destructive fit/fill/crop and rotation.
- Keeps preview geometry consistent with export for portrait, rotated, anamorphic and RGB recordings. Frame keys use decoded timestamps for variable-frame-rate media.
- Protects original recordings and existing destinations through identity checks, cancellation, verified export replacement and atomic saves.

Physical HDR color/brightness, monitor/DPI/accessibility behavior and concurrent game/Shadowplay recording still require acceptance evidence. Metadata and screenshots do not certify HDR output. Test those scenarios before approving a release. Hard cuts remain the default; transitions follow after the rewrite.

Keep original schema-1 project files when saving upgraded schema-2 projects. Previously published 1.0.x packages remain available for rollback.
