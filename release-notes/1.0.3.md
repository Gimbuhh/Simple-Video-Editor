## Added

- When the Recordings library contains more than one clip, **Add to timeline** adds the selected recording and **Add all to timeline** adds every recording in library order.
- Adding all recordings includes those hidden by search, preserves existing timeline edits and gaps, and can be undone or redone as one action.

## Changed

- Timeline buttons share one row. Recording thumbnails sit beside names and durations, leaving more clips visible in small windows.
- Recordings has more room for filenames and a draggable divider. Focus the divider and use arrow keys to resize it with the keyboard.
- The preview stays centered at the video's display aspect ratio as the window changes size, including portrait, rotated and non-square-pixel recordings. It fits the whole frame without stretching or cropping.
- Builds create a shortcut named for the app version, including alternate output folders.

## Fixed

- Projects cannot silently access network recording paths, including remote link targets. Local links are resolved before media access; unsupported linked/cloud locations must be copied to a local folder.
- Project timelines outside the supported time range are rejected. Ruler drawing has a fixed work limit and scale-aware tick spacing, and long-timeline zoom no longer produces an invalid clamp range.
